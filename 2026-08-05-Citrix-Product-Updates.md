## NetScaler (docs.netscaler.com)

### NetScaler Console Service
**Updated: August 4, 2026** | [What's New](https://docs.netscaler.com/en-us/netscaler-console-service/release-notes/whats-new.html)

- **File integrity monitoring extended to Linux-based VPX instances** — NetScaler Console can now detect unauthorized file and configuration changes on NetScaler VPX instances running on the Linux-based platform (CTXENG-67609).
- **Fixed: WAF and Bot policies disappearing after a few days** — Resolved an issue where WAF and Bot policies configured on NetScaler Console would disappear and only reappear after a manual edit or toggle (NSHELP-44177).
- **Fixed: ACME certificate issuance/renewal failures with Infoblox DNS provider** — Resolved failures during ACME certificate issuance and renewal when using the Infoblox DNS provider for DNS-01 domain validation (NSHELP-44000).
- **Fixed: Custom sync to Global sync transition failure** — Resolved an issue preventing the transition from Custom sync to Global sync on the Zero-touch Certificate Management page (NSHELP-44249).
- **Fixed: SSL certificate download 404 error** — Resolved an issue where downloading SSL certificates stored in subdirectories under `/nsconfig/ssl/` returned a "404 - File not found" error (NSHELP-44305).
- **Fixed: agents incorrectly reported as Down during inventory core dumps** — Resolved an issue where NetScaler Console incorrectly reported agents as Down during inventory core dumps (NSHELP-44426).
