# Citrix Product Updates — 2026-07-31

Summary of "What's New" documentation updates published in the last 24 hours (2026-07-30 to 2026-07-31) across [docs.citrix.com](https://docs.citrix.com), [docs.netscaler.com](https://docs.netscaler.com), and [docs.xenserver.com](https://docs.xenserver.com).

## Citrix

### Citrix DaaS

- Machine catalog experience enhancements in Studio: naming scheme now shown in catalog details, "View Machines" promoted to a top-level action, and "Delete Machine Catalog" moved into the "More" menu. ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- Citrix Advisor: new environment checks added — Cloud Connector-to-StoreFront communication, placing StoreFront servers in low-latency networks, reviewing machines stuck in extended maintenance mode, and reducing troubleshooting time via Always On Tracing. ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- Configuration logging in Web Studio can now extend search scope to include low-level operation details (e.g., machine name, VDI name). ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- Autoscale can now exclude draining machines (due to scheduled restarts) from capacity buffer calculations for multi-session OS delivery groups. ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- Citrix Aidrien chat responses about machines/sessions now include deep links straight into the DaaS console view with filters pre-applied. ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- AWS account connection in Web Studio: BYOL setup is no longer required during account connection — it can now be configured separately afterward via "Set up BYOL." ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- Faster Active Directory domain/OU selection via a search box in the Location (domain) drop-down during machine catalog creation. ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))
- Task Center added a new "Recurring" tab (recurring/scheduled tasks) alongside the existing "Recent tasks" tab, plus search/filter and manage actions for both. ([source](https://docs.citrix.com/en-us/citrix-daas/whats-new.html#july-2026))

## XenServer

### XenServer 9 (Preview / Early Access channel)

- Added support for new guest OS templates: AlmaLinux 8, AlmaLinux 9, and AlmaLinux 10. ([source](https://docs.xenserver.com/en-us/xenserver/9/whats-new/early-access))
